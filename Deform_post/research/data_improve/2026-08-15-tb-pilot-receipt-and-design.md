保真，成为语料质量的**试金石对照**。

## 3. 语料净化链（可复用生产资产，联络表全存证）

宽松统计初筛（金属 10%/黑角 5%，612 候选）→ DINOv2 致密簇排序（300）→

统计阈值无法区分湿润眩光与钢材（同为亮+低饱和），语义级过滤不可省。

## 4. 分辨率天花板的破解路径（重要更正，含 2026-08-15 二次更正）

160px 天花板是**本轮语料提取方式的天花板，不是数据的天花板**——但幅度
须按第一手探测更正：`D:/Data Processor/Origin_data`（目录实名如此，代码
与本档旧拼写 Processpor 已订正）的 NN.mp4 为 640x360，且上游
`Image2Force Data` 原始配对视频同为 640x360——**全链路不存在更高清源**，
本档初版"高分辨率视频"的量级推定作废。实测 FOV 圆直径：弦长最小二乘拟
合 ≈485px、亮域包络 ≈516px（圆被上下裁切），序列化管线压至 256px，即原
生直采相对现有语料仍有 **≈1.9 倍线性（3.6 倍面积）**的真实增益：旧
160px 裁片脚距等效原生 ≈303px（本轮取 256/288/320 三档），LoRA 上采样
从 3.2 倍降至 1.6 倍。工序已执行（2026-08-15，所有者批准）：seq04 剔
除，31 段全覆盖，粗筛 2180 裁片（金属启发式按原生分布重标定
V>235/S<45<=0.12）+ 124 张全视野底板；DINOv2 致密簇 1300 -> CLIP 两轮
841 -> **735 张净化终库**（v3 的 3.5 倍量、2 倍分辨率）。

## 4b. v4 连续性轮回执（2026-08-15，割裂感裁定后的三臂横评）

所有者裁定"拼贴割裂感为主要问题"后的机理定谳：瓦片缝与 UV chart 缝
都是**图集空间合成**的固有伪影；器官级连续纹理必须在**视角空间**合成
再泼溅回 UV（三维相邻处获得图像相邻内容，与 chart 布局解耦）。

| 臂 | 构成 | 目检（生产约定渲染） | DINO 距离* |
|---|---|---|---|
| v4-P 纯投影 | 全视野真实底板轮廓极坐标变形 -> 10 视角渐进泼溅 | 器官连贯、血管连续、色调接近；残留变形拉丝与苍白斑 | **0.667** |
| v4-L 全生成 | LoRA v4（735 张原生语料）+ 深度 ControlNet 渐进绘制 | 判负：高饱和拼贴混乱（深度条件锁形不锁外观布局） | 0.722 |
| v4-H 混合 | v4-P 初值 + LoRA 0.45 强度整幅精修 | 判负：首视角即身份摧毁，铬金属/器械状幻觉（语料残余器械统计被先验放大） | 0.745 |

*DINO 距离 = 器官内部裁片对净化真实裁片的 DINOv2 余弦距离；标尺：
真实内部离散 0.136，白模生产渲染 0.910。v4-P 收掉白模->真实距离的
约 31%。五轮工程修复入档：覆盖判定阈 1e-4->0.05（否则擦边首占锁死
陡峭面）、径向采样压缩 0.88（避开底板苍白外圈）、泼溅视角 1024（消
织网摩尔纹）、极角补 2 覆盖视角、144 分箱（消锯齿）。

**验收渲染口径修正**：0.19 legacy 可视化器不渲 obj 纹理；生产纹理渲
染路径 = 共享顶点中点细分 x4 + 图集双线性烘焙顶点色（约 51 万顶点，
复用 C1 线已验证的顶点色+光照管线）；**法线必须从粗网格插值传播**，
细分后重算法线会导致面片化"贴花"假象（曾被误诊为纹理缺陷）。渲染帧
与真实帧的湿润镜面观感差距主要由光照产生——生产渲染器光照口径是否
升级（镜面项）属所有者裁决项，与纹理路线正交。

## 4c. T-B-G 底色画布+生成血管轮回执（2026-08-15，所有者路线令）

所有者两令：(1) 取材必须限定器官本身（v4-P 曾混入腹膜背景组织，收
回）；(2) 管线改为 底色采样 -> 基础画布 -> 扩散生成自洽血管 -> UV 上
模 -> 光照多视角渲染批产。执行样品（批产未启动）：

- 取材：肾本体手工椭圆标注（颜色启发式分不开肾被膜与同为亮粉的腹
  膜；手工标注与 inputs/annotations 惯例一致，批产时逐序列一枚）∩
  亮度门 ∩ 内蚀；48px 样窗逐片剔除眩光/血管像素后取底色统计（该表
  面不存在同时无眩光无血管的干净窗——实测中位 255 峰值+6% 暗像素）。
- 画布：1024 图集 = 采样色调低频场 + 实测颗粒度噪声，无结构。
- 血管作画（视角空间渐进，机理同 §4b——平面图集直生会被 chart 边
  界切断）：**LoRA 驱动双强度 (0.55/0.7) 判负**——玻璃/碎瓷质感、血
  管成多边形裂纹；根因定谳 = 语料眩光常驻，LoRA 把镜面反光学成材质
  （与 v4-H 同根，负面提示词不可救）；**弃 LoRA + 哑光反照率提示词
  的原版 SD1.4 成立**——玻璃/器械幻觉清零、底色保持、出现器官级分
  叉血管树；v2 加逐视角血管密度门 (<1.2% 重采样) 与去 seamless 措辞。
- 残留缺陷（待所有者定向）：血管颜色部分漂白/偏蓝（真实为暗红）、
  视角间密度不均、局部织物状纹理残余。
- 结构性教训入档：**含眩语料训练的生成先验不可用于反照率贴图作画**；
  反照率化语料（裁片眩光修补后重训）为 LoRA 复活的唯一路径。

## 4e. mixed_tex_v1 五折试金石回执（2026-08-16，冻结协议原样）

哨兵折（预注册）先行收官后发射；三 Ada 车道全 rc=0，逐折报告直读
（不经 cross_fold_summary），每折唯一性核验通过。协议主指标 =
magnitude_mean_absolute_error（以 c1c3 fold1 报告 0.6622 逐位核实
语义后才对表）。

| 折 | 白模基线 | mixed_tex_v1 | 改善 |
|---|---|---|---|
| 0 | 1.2229 | 0.8653 | 是 |
| 1 | 1.2698 | 0.7267 | 是 |
| 2 | 2.0897 | 0.8118 | 是 |
| 3 | 0.6847 | 0.6222 | 是 |
| 4 | 1.5189 | 0.5669 | 是 |
