# 实验配置清单 C1C3-C2-20260812（组合数据五折训练，交检即开跑——所有者 2026-08-11 裁决第 4 项）

## 1. 目的、假设与预注册判定

- **假设**：在 DR-C1（外观随机化）之上叠加 C3（接触点多样性，62 变体单元）进一步改善零真实标签 c2 迁移。
- **主指标**：真实测试集 magMAE；差距闭合率 = (1.3572 − magMAE)/(1.3572 − 0.2316)（沿 DR-C2 公式与已入库基线）。**角度仅记录不入判定（所有者 2026-08-11 裁定）。**
- **预注册判定规则（双层，防事后解释）**：
  1. 组合 vs 白模基线：差距闭合率 ≥ 20% 且五折同号 → 组合"有效"；
  2. **C3 边际**（本实验的真正问题）：同折配对比较组合 vs DR-C1（pooled 0.9114±0.2569）——**5/5 折同号改善 → C3 边际"有效"**；4/5 及以下 → "不可判定，需多种子复测"（依据：折3 复测实测的单种子噪声量级）。不得把噪声内差异宣称为改善。
- 诚实预告：两臂均为单种子证据；边际效应若小于种子噪声（DR 臂实测 std 0.026），预注册规则会正确地判"不可判定"。

## 2. 数据（校验门收据，跑前填写）

- 组合集 `datasets/mixed_dr_c1c3_v1` = 真实半（31）+ DR-C1 孪生半（31）+ C3 变体（62），共 124 条目、210,088 样本；真实+孪生半与已验 `mixed_dr_c1_v1` inode 同一；C3 单元逐一校验帧数=基序列孪生帧数、样本 id 精确匹配 `deformed_s{接触}_v*`、磁盘单元与分配表逐一相符。
- **样本 id 跨单元重复的透明申报**：不同基序列共用同一接触时样本 id 相同（id 只编码接触+帧号）。训练与 split 均为索引级，评估只在真实半（id 唯一）——无影响；特征缓存 id 仅作标签。
- **split**：专用著作工具（仓库外 `DataFlow/KiDKNet/tools_c1c3/`）**逐字克隆基线 cv5 折成员**（配对性继承而非重推导），把每个基 id 的全部合成材料（孪生 + 2 变体）与该 id 同折路由；**变体泄漏守卫断言**：测试 id 的任何合成材料（含变体）不得进入训练/验证——C3 变体重放测试序列的真实力波形，此守卫是本实验的核心泄漏防线。不改动任何既有 KiDKNet 脚本（现行 `author_cv_splits.py` 的精确键路由会静默丢弃变体、其 50:50 断言在 3 倍合成半上必然崩溃——故新工具而非改旧）。
- 验证集组成变化的透明申报：val = val id 的全部合成材料（孪生+变体，约 3 倍于基线 c2 的 val）——模型选择信号仍来自同一批 val id，材料扩容属"数据改良"操纵变量的一部分。

## 2b. 启动期事故记录（如实申报，2026-08-12）

1. **metadata 漏改**：组合目录 metadata.yaml 从基目录克隆时未更新 `total_samples`（105044），加载器以其校验 split 尺寸（210088）→ 折2 首发失败 rc=1。已修（total_samples=210088）并全量重发；此字段校验是构造脚本 G 门的盲区，教训入库。
2. **并发缓存 OOM（两轮，最终结论）**：训练进程各自全量 RAM 锁页缓存 210k 样本（bfloat16 ~77G/进程，缓存构建期另有 float32 瞬时峰）。首轮三路并发缓存 → 折2 遭 OOM（rc=-9）；改两路+接力后，接力守望与 run_cv 折间推进发生**调度竞态**（折0 死后守望即刻发射折2，而折0,3 路内部转入折3 缓存 → 一度又三进程缓存并发）→ 折0、折3 相继 OOM。**经验约束定案：任意时刻至多一个进程处于缓存期**（流式加载路径经查不可用于训练——按需模式每样本整批反序列化）。**最终调度（零协议改动）**：折1,4 链（卡2）+ 折2（卡3）保留在跑（恰好满足约束）；折0,3 由守望 v2 接力——仅当折2 路收官且剩余路经 GPU 利用率三连检确认处于训练期（或全部退出）后才发射，附启动前残留清理。墙钟诚实预估延至 **24–44 小时**。

### 2c. H100 投入与内存定律定案（2026-08-12，所有者解除 H100 保留）

### 5.3 预注册终裁

- **第 1 层（组合 vs 基线）：判"有效"**——差距闭合率 **(1.3572−0.6755)/(1.3572−0.2316) = 60.6%** ≥ 20% 且 **5/5 折同号**（无需任何附加条件，较 DR-C2 的 39.6% 接近翻倍）。

- 角度（仅记录，所有者裁定不入判定）：pooled 55.4°→63.3° 变差；折3/折4 改善。
